# What is missing

Three parts: what is ready, what the backlog still needs (lesson 08 retrofit), and what is deliberately not in the system. The last part ends with the **P list**: every rule in these pages that has no source yet, for the owner to accept or reject.

## 3. Not in the system, and why

| Component                 | Decision                            | Reason                                                                                                                                                                                    | Use instead                                                             |
| ------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Action menu (row actions) | left out (batch 4 Q1)               | the admin has no row actions today (batch 4 inventory); the owner chose a megamenu for the store                                                                                          | buttons on the detail page                                              |
| Popover                   | left out (batch 4 Q2)               | the metric definitions stay visible text (batch 4 Q2)                                                                                                                                     | visible text under the metric; `Disclosure` for an optional explanation |
| Drawer / side panel       | in the system (storefront v2, cart) | a side panel covers part of the page; it is used only for the cart, and the cart page stays                                                                                               | the [Drawer](?path=/docs/primitives-drawer--playground)                 |
| Tooltip                   | left out                            | information needed to act must not sit in a hover hint (Etap 4 plan, WCAG 1.4.13)                                                                                                         | text next to the control                                                |
| Toast                     | left out                            | an error must stay visible until the user acts (**P**: see the P list); a short confirmation is inline text                                                                               | an Alert with `role="status"`, or inline text                           |
| Avatar                    | left out                            | the products have no user pictures; the store has no user profiles beyond the account                                                                                                     | a text name                                                             |
| Switch                    | left out                            | a setting that applies at once is a button that states its outcome; the product publish control is a button in code, while the Etap 4 plan first assumed a checkbox (a deviation to note) | a button that states its outcome, or a Checkbox saved with the form     |
| Base UI Select            | left out (batch 2 Q1)               | the native select is simpler and works without JavaScript                                                                                                                                 | `NativeSelect`                                                          |
| Indeterminate checkbox    | left out                            | there is no bulk selection in the app                                                                                                                                                     | none                                                                    |
| Segmented control         | left out (batch 2 Q3)               | a separate component for the theme switch was rejected; the switch stays native (spec A5)                                                                                                 | `Tabs` or `TabsNav`                                                     |
| Accordion                 | left out (batch 3 decisions)        | the store uses one disclosure at a time                                                                                                                                                   | `Disclosure`                                                            |
| Row selection in tables   | left out                            | no bulk action exists in the admin (batch 3 decisions removed the selected row style)                                                                                                     | none                                                                    |
| Spinner                   | left out (batch 3 decisions)        | the only loop is the skeleton pulse (tokeny §5)                                                                                                                                           | `Skeleton` in a group, or a button in its pending state                 |
| Collapsible               | left out (batch 3 decisions)        | `Disclosure` covers the same need                                                                                                                                                         | `Disclosure`                                                            |

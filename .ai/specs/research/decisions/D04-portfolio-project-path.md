# D04 — CommerceOS is built as a portfolio / course project

- Date, owner: 2026-10-14, product owner (project author), confirmed in the `om-discover` session.
- Context and the options weighed: (a) a portfolio/course project, where success is a working demo and engineering quality for reviewers and the merchant problem stays an untested hypothesis; (b) a real product, which would first check through interviews that store owners have the problem, before building the Copilot. Both options were offered by the agent; the owner chose (a).
- Decision and why: (a). Build the 5-week MVP described in `.ai/specs/2026-10-13-commerceos-mvp.md` (see D01) for the course and portfolio. The merchant problem is accepted as a working hypothesis, informed by the owner's practitioner experience (`interviews/2026-10-14-practitioner-shopify-builder.md`), and is not validated with independent store owners before building.
- Consequences, and what would make us revisit it: claims about store owners' needs stay hypotheses. Market-facing claims (demand, willingness to pay, superiority over agencies or existing tools) are out of scope for this brief. Revisit if the project is to become a real product: then run the merchant interviews in `2026-10-14-interview-guide-merchant.md` first.

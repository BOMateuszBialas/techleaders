# 2026-10-24 — Storybook story tests break under a non-ASCII Windows path; stories must not live in a dot-directory; the hook flags some shell text as a .env glob

`@storybook/addon-vitest` 10.6.3 compares `import.meta.url` with the test path through `convertToFilePath`, which decodes only `%20`, so under `C:\Users\Użytkownik\…` every story reports "No test suite found" (CI on Linux is fine). `packages/app/vitest.storybook.config.mts` carries a small Vite plugin that wraps the call in `decodeURIComponent`; remove it once Storybook fixes the bug. The addon's glob also skips dot-directories, so stories in `.storybook/` never become tests: they live in `packages/app/stories/` (which also keeps them out of the coverage `include`). MDX files do not get the `@/` tsconfig alias in Vite: import with a relative path. Separately, the PreToolUse hook blocked Python heredocs whose text contained a regex like `.*?` or the literal env file name in prose; edit such files with the Edit tool, not a shell heredoc.

# 2026-10-17 — A production build evaluates a module once per server layer, so a per-evaluation `globalThis` cache key ping-pongs (#57)

`container.ts` stamped its cached container with a per-evaluation `Symbol` (for dev hot reload, #35). In `next start`, route handlers and pages each evaluate their own copy of the module, so every alternating request disposed the other layer's container (ORM and Better Auth pools) and rebuilt it; a request still in flight then failed, which surfaced as an intermittent Better Auth "Failed to get session" 500. A production build now uses one shared owner (`Symbol.for`), and the per-evaluation key applies only outside production. Tell-tale sign: a one-time init warning (Better Auth's low-entropy secret warning) logged on every page/route alternation. Better Auth log lines now carry a sanitized summary of the underlying error (class, code, constraint, cause; no driver message).
